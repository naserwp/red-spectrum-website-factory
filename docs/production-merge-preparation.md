## Brand and domain preparation

The V2 header already uses `public/v2/brand/red-spectrum-wordmark-v2.png`, a Red Spectrum WebFactory lockup. This pass aligns its accessible name, browser title, favicon with the existing Red Spectrum `public/favicon.svg`, root metadata, and OpenGraph/Twitter metadata. Homepage, designs, and privacy have explicit factory-domain canonicals; design details have their own canonical. The existing logo PNG is used as the social preview image. Verify the actual card crop in a social preview tool before launch.

`app/robots.ts` disallows crawling on non-production Vercel environments. A production Vercel environment allows only public factory paths while disallowing admin, API, client, request, checkout, processing, and preview paths. `app/sitemap.ts` lists only `/`, `/designs`, and `/privacy` in the production environment. Customer-specific page metadata remains owned by its existing route; the factory sitemap does not include customer records.

The intended factory origin is `https://webfactory.redspectrum.ai`. Customer preview URLs remain `https://preview.redspectrum.ai/[slug]`. Existing `proxy.ts` and branded preview route keep their host checks. No redirect, domain assignment, or DNS change was made. At audit time the factory host was unavailable and the REAL SPIEL branded preview returned 404; neither is evidence of deployment readiness. The connected Vercel account did not expose the WebFactory project, so project root/framework/build settings, domain assignment, and environment-variable presence could not be confirmed live. `vercel.json` specifies Next.js and `npm run build`; it also declares an existing lead retry cron, whose secret and delivery gates must be checked before any production deployment.

Required server-only production configuration to validate before launch: `LEADS_DATABASE_URL`, `WEBFACTORY_ADMIN_USER`, `WEBFACTORY_ADMIN_PASSWORD`, `WEBFACTORY_SESSION_SECRET`, `LEADS_RATE_LIMIT_SALT`, and existing lead delivery/cron variables if those flows are approved. Keep `WEBFACTORY_BUILD_EXECUTOR` unset, worker secrets/`VERCEL_TOKEN` unarmed, and email enable flags false unless separately authorized. `WEBFACTORY_STAGING_DATABASE_URL` belongs only to branch previews, never Production. `CUSTOMER_INTELLIGENCE_BASE_URL=https://intelligence.redspectrum.ai` is a server-only reserved endpoint; leave `CUSTOMER_INTELLIGENCE_API_KEY` unset. `CUSTOMER_INTELLIGENCE_API_URL` is the older reserved placeholder. Neither is browser-visible and `getCustomerProfile` always returns unavailable. No payment variable or execution path is introduced.
