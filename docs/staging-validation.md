# RS WebFactory V2 staging validation

The staging checkout has a separate PostgreSQL 18 cluster under the ignored `.sites-runtime/staging-db/` directory. `npm run staging:db:setup` initializes it on loopback port 55433, applies the existing lead and WebFactory migrations, and writes random local credentials to ignored `.env.staging.local` and `.env.development.local`. It refuses a different checkout, branch, database host, database name, or an existing mismatched development environment. It never reads or changes the production database configuration.

Run `npm run staging:seed:real-spiel` to create the synthetic REAL SPIEL request, generated fixture brief, confirmed local slug, and synthetic build-ready state. The fixture uses `qa+real-spiel@example.invalid`; it represents no real admin or customer approval. The customer site remains a draft with its contact form disabled. `npm run staging:test:real-spiel` verifies the database record, admin handoff, local route, preview alias, contact endpoint, and absence of customer approval. Run the app with `node --env-file=.env.staging.local node_modules/next/dist/bin/next start -p 3017` after a build.

For a Vercel branch preview, backend database access now requires `WEBFACTORY_STAGING_DATABASE_URL`. When it is absent, admin and request storage fail closed instead of using `LEADS_DATABASE_URL`. Branch previews also block lead and internal email delivery. `npm run staging:test:isolation` verifies these guards. No remote staging database has been provisioned, so remote preview backend workflows remain unavailable.

The registered draft site can be inspected at `/real-spiel-cleaning-company` on the staging deployment; `/preview/real-spiel-cleaning-company` redirects there. The admin workspace labels this as a staging route and keeps branded preview verification separate. `preview.redspectrum.ai/real-spiel-cleaning-company` still returns 404 because that host is not serving this branch. Connecting it requires a separately approved domain/deployment decision; no DNS or production mapping was changed here.

The controlled build worker is not configured for isolated staging. The admin offers a copyable/downloadable prompt and requirements from the saved brief and slug. Build jobs, Preview Ready, customer approval, deployment, email, and payment remain gated. The REAL SPIEL contact form stays disabled until a verified recipient and explicitly authorized safe test are available.
