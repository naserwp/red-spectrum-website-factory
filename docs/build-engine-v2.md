# Customer site contract 2.0

New Admin jobs use instruction_version customer-site-v2. Existing v1 jobs and customers remain supported. The generator returns validated data, never repository code or shell instructions. Reviewed rendering components own the CSS, typography, section variants and responsive behavior. Only customer config, named private Markdown/JSON delivery files and named local SVG/WebP assets are permitted.

Composition supports editorial, panorama and journal heroes; balanced/compact navigation; classic/editorial/modern typography; generous/compact spacing; split, statement, image, steps, columns and contact sections in page-specific order. New files cannot target shared app/components/lib/scripts paths. SVGs are constructed by trusted code with escaped text; generated text rejects HTML and external URLs.

The licensed image pipeline uses a closed Unsplash source catalog, HTTPS with redirects disabled, image decoding and bounded resizing to local WebP. Source/license/hash/dimensions/bytes are recorded privately. Images are illustrative, never claimed company projects. Customer-provided contact facts remain draft; services are inquiry-led until separately confirmed. Lead delivery and Myndy are disabled.

QA runs five pages at 320/375/768/1024/1440/1920. Server completion independently requires six-width pass evidence for v2. Legacy QA remains accepted for legacy jobs. Checkpoint symlink and scope guards remain active.

The branded domain bridge serves only a current canonical slug's verified ready_for_review record. It sends the existing Vercel automation bypass server-side to the verified deployment only. No cookies, credential URLs, admin routes, APIs, private packages or arbitrary paths are forwarded. Production customer routes remain absent until separately published. DNS is not changed.

Delivery notes live outside public/. An every-page PDF is a separately generated private review artifact, not part of the immutable source fingerprint.

Limits: the worker uses reviewed compositional primitives and stock catalogs, not unrestricted AI code generation. New trade claims require confirmed data and review. Public preview access is intentionally available on the branded preview domain while underlying deployment protection remains enabled.
