# Swenzy identity concept
Original proposed identity, not a pre-existing official customer logo.
Direction: midnight navy #0B1D30, warm white #FAF8F3, amber #F1B44C.
A stylized S/highway mark evokes movement; a bold wordmark supplies legibility.
