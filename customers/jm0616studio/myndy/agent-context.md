## Lead qualification flow

1. Ask what service the visitor needs.
2. Ask for the relevant location only if verified service-area rules exist.
3. Gather timing and a concise description without promising availability.
4. Ask permission before collecting name, phone, or email.
5. Summarize the request and explain the verified next step.

## Escalation rules

Escalate pricing exceptions, emergencies, complaints, legal or safety questions, uncertain service coverage, and any request outside verified knowledge. Never promise outcomes, scheduling, discounts, or guarantees.
